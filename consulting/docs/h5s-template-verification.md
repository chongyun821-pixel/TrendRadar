# TrendRadar AI 컨설팅: 한화 H5S 양식 확인 현황

확인일: 2026-10-22

## 확정된 요구

TrendRadar에 추가할 AI 컨설팅 기능은 한화 H5S의 실제 양식과 작성 방법을 따라야 한다. 일반 컨설팅·맥킨지 방식으로 재구성한 양식은 이 요구를 충족한 것으로 취급하지 않는다. 기존 procurement-radar 프로젝트의 파일과 DB를 수정하지 않는다는 제한은 유지한다. 이번 작업은 현재 워크스페이스의 조사 문서만 갱신한다.

## 확보한 원자료

현재 `참고자료/`의 교재 사진 8장과 판독본 `docs/reference-extraction.md`를 확인했다. 개요 사진 `20261021_191820.jpg`에는 한화 HRD Center 표기와 단계별 작업·산출물이 보인다. 나머지 사진은 문제정의와 이슈트리를 중심으로 한다.

네 산출물의 전용 양식, 작성 순서, 작성 예시, 평가 기준은 현재 확보한 사진에 없다. 공개 웹 검색에서도 해당 네 산출물의 한화 H5S 원본 양식을 식별하지 못했다. 이는 자료가 공개되어 있지 않다는 단정이 아니라 이번 조사에서 확보하지 못했다는 의미다.

## 추가로 필요한 원자료

사진에 나온 교재의 후반부에서 다음 부분을 확인해야 한다. 전체 교재보다 해당 양식과 작성 설명·예시가 있는 면이 우선이다.

1. 작업계획: 작업계획서 빈 양식, 작성 설명, 작성 사례.
2. 분석: Governing Thought 피라미드 도식, 작성 원칙, 작성 사례.
3. 권고안 개발: 스토리보드 양식, 메시지·도표 전개 방법과 사례.
4. 권고안 개발: 권고안 작성 설명 및 완성 예시. 고정 양식이 있는지도 확인.
5. 함께 제공되는 실습지나 과제 평가표가 있으면 필수 항목과 검토 기준 확인.

확인 가능한 교재 파일·폴더 경로 또는 링크를 사용자에게 요청한 상태다. 사내 시스템 접근이나 담당자 연락은 수행하지 않았다.

## 원자료 확보 후 제작 절차

1. 원본을 OCR하고 표·도식·레이아웃을 함께 판독한다. 원문과 페이지 위치를 기록한다.
2. 양식 항목·배치와 작성 규칙을 추출하고, 잘린 부분이나 불명확한 문구는 미확인으로 남긴다.
3. 작성 사례와 대조하여 각 필드의 역할과 선후관계를 확인한다.
4. 양식마다 입력, 생성 결과, 필수 작성 규칙, 품질 검토 기준을 정의한다. 원문 기준과 제품 편의 기능을 구분한다.
5. 대화·답변·TrendRadar 근거를 해당 필드에 연결해 추천 답변과 초안을 생성한다. 교재의 교육용 수치를 실제 분석 근거로 사용하지 않는다.
6. HTML·PDF·Word의 배치와 내용이 확인된 H5S 양식을 따르는지 검수한다.

## 보조 조사 자료의 위치

`docs/report-methodology-research.md`는 맥킨지와 민토의 공개 일반 원칙을 정리한 보조 자료다. 위 네 양식의 한화 원본을 대신하는 사양이나 H5S 검증 근거로 사용하지 않는다.
