# 국가 무기체계 수주 기회 요약

지도 카드의 Word 버튼에서 요청하는 경영진용 요약이다. 선택한 국가와 무기체계 한 쌍만 다룬다. 최신 조사와 검증을 마친 자료로 prepare_report를 호출한 후 작성한다. 확인할 수 없는 항목은 미확인으로 남긴다.

## 분량과 구조

- A4 세로 1~2쪽이며 별도 표지를 만들지 않는다. 여백은 위아래 17~20mm, 좌우 18~20mm를 기본으로 한다.
- 첫 페이지 상단에 국가와 무기체계를 포함한 명확한 제목, 기준 연도, 조사 기준일을 표시한다. 핵심 판단은 첫 2~3문장에 제시한다.
- 현재 주력 장비, 보유 수량, 도입 시기, 교체 예상 시기, 예상 수량과 금액을 간결한 표로 비교한다. 진행 사업의 공급자, 선정 단계와 계약 및 인도 일정을 구분한다.
- 한화의 신규 수주 기회, 이미 공급자가 정해진 사업의 후속 MRO 또는 현지화 가능성, 추가로 확인해야 할 불확실성을 짧은 문단으로 제시한다.
- 케이스별 근거 표는 작성 자료의 evidenceTables를 사용한다. 1~2쪽 안에서 읽히도록 압축하되, 확인 사실과 예측, 통과 조건과 제외 사유를 보존한다.
- 중요한 주장과 수치는 출처 번호를 연결하고, 마지막에 원문 제목, 날짜, URL을 짧게 기재한다. 본문 설명을 서술문 대신 큰 표 안에 나열하지 않는다.

## 현재 PDF와 PPT 출력의 스타일 적용

- prepare_report가 제공한 한화 로고를 첫 페이지 우상단에 가로 30~35mm로 넣고 종횡비를 보존한다. 별도 표지나 큰 빈 공간을 만들지 않는다.
- HORUS와 Hanwha Observation & Reconnaissance Unified System을 첫 페이지 상단 브랜드로 표시한다.
- 맑은 고딕을 기본으로 제목 19~22pt, 소제목 11~13pt, 본문 10~11pt, 표 9~10pt를 사용한다.
- 현재 가로형 보고서와 같이 남색 #204d79와 주황색 #f37221을 강조색으로 쓴다. 제목과 소제목은 남색, 강조선은 주황색과 남색을 사용한다. 이 요청의 지정 스타일을 일반 문서 기본 스타일보다 우선한다.
- 수치 표의 헤더는 남색 바탕과 흰 글자, 행은 흰색과 연한 회색 #f2f5f8을 번갈아 적용한다. 표 테두리는 연한 회색이며 금액은 오른쪽 정렬한다.
- 바닥글은 HORUS / 예상 수주 전망 보고서와 쪽번호를 표시한다. 전체 본문은 검정 또는 #333a42를 사용한다.

## 작성과 검수

기존 Documents 또는 native docx 스킬과 문서 도구로 편집 가능한 Word 파일을 직접 작성한다. Markdown 파일을 Word로 바꾸는 범용 변환기로 대체하지 않는다. 모든 페이지를 렌더링해 정확히 1~2쪽인지, 한글과 표가 잘리지 않는지, 로고가 보이는지 확인한다. 필요한 경우 내용을 다듬고 다시 렌더링한다. 내용과 배치 검수를 끝낸 파일만 publish_artifact에 preparationId와 실제 review를 전달해 등록한다.
