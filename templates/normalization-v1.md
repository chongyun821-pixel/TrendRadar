# 조달 자료 정제 기준 v1

국가는 ISO3, 무기체계는 sph, ifv, sam, mrl, frigate, ssk로 정리한다. 모델의 원문 표기와 변환 전 값은 정제 기록에 보존한다. 수량은 개수, 금액은 원통화의 기본 단위로 저장하며 통화는 대문자로 표시한다. 통화 환산은 자동으로 하지 않는다.

사업 단계는 검토, 계획, 입찰, 계약, 인도, 취소로 구분한다. 계약량과 인도량, 현재 보유량은 합산하지 않는다. 알 수 없는 수량은 0으로 채우지 않는다. 정비만으로 수명 연장을 추정하지 않는다.

기존 기록에 없는 항목을 추가하되 기존 식별자와 근거는 유지한다. 같은 사업 식별자나 배치 식별 기준으로 서로 다른 값이 들어오면 상충을 반환한다. 기존 배열을 전부 교체할 때는 replaceFields에 해당 필드명을 명시하고 변경 근거를 제출한다. 취소된 계획이나 계약 등 선택 항목을 없앨 때는 removeFields에 해당 이름을 명시한다. 단순한 추가와 상충 값의 채택을 구분한다.

형식과 원문 인용 검사는 자동화한다. 인용문이 실제 주장을 뒷받침하는지는 조사자가 검토한다. 적용 시점에 근거와 데이터 버전 및 실행 상태를 다시 검사한다.
