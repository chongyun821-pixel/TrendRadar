# 한화그룹 '글로벌 트렌드 레이더' 구축

> 한화 신입사원 AI 실습 과제 · **ASSIGNMENT 02 / 05** · 주제: **트렌드**

R&D · 마케팅 · 영업 · 경영지원 등 모든 부서는 외부 트렌드에 민감해야 합니다.

## 📌 배경 시나리오

> 시장 변화가 매우 빠릅니다. 여러분은 한화그룹의 **'미래전략실'** 소속으로,
> 그룹의 주요 사업(방산, 에너지, 금융, 우주 등) 중 하나를 택해 **글로벌 최신 트렌드**를 자동으로 수집하고 분석하는 시스템이나 리포트를 기획해주세요.

## 🎯 우리가 해결해야 할 과제

1. **사업 분야 선택**: 방산, 에너지, 금융, 우주 등 그룹 주요 사업 중 하나를 고릅니다.
2. **자동 수집**: 선택한 분야의 글로벌 최신 트렌드를 사람이 일일이 찾지 않아도 모이게 만듭니다.
3. **분석과 정리**: 모은 자료에서 핵심 흐름을 뽑아 의사결정에 쓸 수 있는 형태로 보여 줍니다.
4. **결과물 제출**: 시스템이나 리포트로 완성합니다.

## 🗂️ 활용 데이터

- 실제 글로벌 뉴스 기사, 산업 동향 보고서
- 주식 · 환율 등 공개 데이터

## 📦 산출물 예시

| # | 산출물 | 설명 |
|---|---|---|
| 01 | **자동화 워크플로우** | 매일 아침 특정 키워드의 뉴스를 크롤링해 요약해 주는 워크플로우 |
| 02 | **시각화 리포트** | 경쟁사들의 공개된 ESG 데이터를 비교 분석한 리포트 |
| 03 | **가상 랜딩 웹페이지** | 트렌드 분석 결과를 바탕으로 기획한 신사업 랜딩 페이지 |
